# CodeCare 💧

**CodeCare** is a gentle VS Code extension that reminds developers to:

- 💧 Hydrate yourself
- 🧘 Stretch a bit
- 💺 Fix your posture
- 💙 Take breaks and care for your well-being while coding

### Features

- Automatically pops up motivational self-care messages
- Starts working as soon as the extension is activated
- Customizable in future (stretch timers, hydration alerts, etc.)
